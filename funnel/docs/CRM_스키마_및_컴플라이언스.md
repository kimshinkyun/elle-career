# CRM 스키마 · 동의 관리 · 컴플라이언스 체크리스트

> 법률 자문이 아닙니다. 아래는 일반 가이드이며, 문구 확정과 발송 전 **변호사·세무사 검토**를 받으세요.

## 1. 저장 구조 (노션, api/lead.js)
| 시트 | 용도 | 규칙 |
|---|---|---|
| 고객 DB | 상담용 리드 (전화번호 기준 병합) | 단계·메모·다음 행동일은 담당자가 편집, 폼 재제출 시 보존 |
| 동의 로그 DB | 동의 증빙 (제출 시점 문구·버전 스냅샷) | **행 추가만, 수정·삭제 금지** |
| 동의 로그의 '철회/수신거부' 이벤트 | 철회·수신거부 | 처리결과 통지 기한(14일) 컬럼에 날짜 기입 |

### leads 컬럼
`lead_id, created_at, updated_at, hospital, name, role, phone, email, specialty, stage, marginal_rate, est_saving_man, lead_grade, consult_request, marketing_consent, ch_sms/ch_email/ch_kakao, consent_at, reconfirm_due, consent_version, status, next_action, owner, memo, utm_*, optout_token, optout_at`

### 데이터 최소화
소득·출자 **원본 금액은 서버로 보내지 않습니다**. 한계세율(%)과 추정 절세액(만원)만 저장해 우선순위를 매깁니다 (`lead_grade` A≥40% / B≥35% / C≥24% / D).

### 연락 가능 여부 판정표
| consult_request | marketing_consent | 연락 가능 범위 |
|---|---|---|
| ✔ | ✔ | 상담 연락 + 선택 채널로 광고 |
| ✔ | ✘ | **상담 신청에 대한 연락만** (홍보 발송 금지) |
| ✘ | ✔ | 선택 채널로 광고만 (상담 전화 영업은 지양) |
| ✘ | ✘ | 연락 금지 (결과 제공으로 종료) |

## 2. 동의 설계 원칙 (폼에 반영됨)
- 개인정보 수집·이용(필수) / 1:1 상담 신청(선택) / 광고성 정보 수신(선택)을 **별도 체크박스**로 분리, 모두 미체크 상태 시작
- 광고 동의 시 채널(문자/이메일/카카오) **개별 선택 필수**
- 광고 동의 안 해도 결과는 동일하게 제공
- 전송자 명칭·수신 내용·철회 방법 문구에 표기, 동의 문구 버전(`CONSENT_VERSION`) 로그 저장
- 2년마다 재확인: 고객 DB의 '재확인 기한'이 30일 이내인 사람을 매주 점검(필터 뷰), 기한이 지나면 광고 발송 중단

## 3. 발송 규칙 (운영)
1. 광고 문자·메일·카톡에는 `(광고)` 표기, 전송자 명칭, **무료 수신거부 방법**(optout 링크)을 넣는다.
2. 야간(21시~다음날 08시)에는 별도 동의 없이 광고 발송 금지.
3. 수신거부·철회를 받으면 즉시 중단하고 14일 이내 처리결과 안내(이 안내에는 광고 포함 금지).
4. 보내는 이름은 **하나로 통일****MAKERS**로 확정, 수신거부·철회 접수 010-8322-5661.
5. 금융 상품이 연결되는 시점부터는 금융상품 광고·권유 규제(적합성·설명의무, 광고 심의 등)가 별도로 적용될 수 있으니, 계산기·콘텐츠는 **세금 정보·교육** 문구로 유지하고 상품 안내는 상담 단계에서 자격 있는 주체가 진행.

## 4. 배포 전 체크리스트
- [ ] 보내는 이름·연락처 확정 → `CONFIG.SENDER_NAME / SENDER_CONTACT`
- [ ] 개인정보처리방침 URL, 수신거부 페이지 URL 준비
- [ ] 보유기간 문구 확정(`CONFIG.RETENTION`)
- [ ] Vercel 배포 + `NOTION_TOKEN` 설정, 테스트 제출 1건 → 고객·동의 로그 행 확인
- [ ] 세율·공제율·한도를 국세청·법제처 원문으로 재확인 (계산기 상단 `BRACKETS`, `DEDUCT_TIERS`)
- [ ] 카드뉴스 CTA 카드의 면책 문구와 인스타 캡션 확인
- [ ] 변호사 검토(동의 문구, 광고 표현, 금융 연계 여부)
- [ ] 8월 계산기가 있다면 이 폼 입구로 교체 또는 연결
