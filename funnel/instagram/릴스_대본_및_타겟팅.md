# 인스타 릴스 대본 3종 + 타겟팅 + DM 자동화

공통 원칙: 처음 1.5초 안에 "누구에게 하는 말인지" + "손해/이득 숫자"를 보여준다. 길이 20~30초, 세로 9:16, 자막 필수(무음 시청 대부분). 마지막 3초는 항상 같은 CTA: **"댓글에 '세금' → 3분 계산기 링크 보내드려요"**. 화면 하단에 작게 상시 표시: *세금 정보 제공 목적의 참고용 추정, 투자 권유 아님*.

## 릴스 1 — 구간 충격형 (가장 먼저 올릴 것)
| 초 | 화면 | 자막/내레이션 |
|---|---|---|
| 0-2 | 계산기 숫자 올라가는 화면 | **"원장님, 같은 3천만원 공제인데 절세액이 이렇게 다릅니다"** |
| 2-8 | 구간표 3줄 (24% / 35% / 38%) | "과세표준 8,800만 초과 35%, 1.5억 초과 38%" |
| 8-16 | 예시 숫자 (2.5억 소득, 3천만원 공제) | "세금 약 1,254만원 차이 (추정)" |
| 16-23 | 한도·조건 경고 | "단, 한도와 조건이 있어서 세무사 확인은 필수" |
| 23-28 | CTA | **"댓글에 '세금' → 3분 계산기 보내드려요"** |

## 타겟팅 (Meta 광고 / 오가닉 병행)
| 항목 | 설정 |
|---|---|
| 목표 | 리드 전환 아닌 **트래픽(랜딩페이지 조회)** → 픽셀 커스텀 전환 "결과 보기"로 최적화 전환 |
| 지역 | 서울·경기·부산 등 개원 밀집 지역부터 |
| 연령 | 33~58세 |
| 관심사(후보) | 병원 경영, 의료 기기, 개원, 의사 커뮤니티 관련 관심사, 고소득 전문직 |
| 제외 | 이미 리드로 수집된 사람(맞춤 타겟 업로드는 **마케팅 동의자만**) |
| 크리에이티브 | 릴스 1·2·3 + 카드뉴스 A·B 각각 소재 테스트, 3일 후 CTR 상위 소재에 예산 집중 |
| 예산 단계 | 소재당 1만원/일 × 3일 → 상위 1~2개로 증액 |
| UTM | `?utm_source=ig&utm_medium=reels&utm_campaign=tax1123&utm_content=reel1` (릴스1) 등 소재별로 다르게 |

※ 의료광고가 아니라 세금·경영 정보 광고이므로 병원 환자 유치 표현은 쓰지 않습니다. 단, 의료기관 관련 표현이 들어가면 의료광고 심의 대상 여부를 확인하세요.

## DM·댓글 자동화
- 트리거 키워드: `세금` `계산기` `절세`
- 1차 자동 DM (링크는 UTM 포함): 
  > 안녕하세요, 원장님! 요청하신 3분 계산기 링크예요 👉 {링크}
  > 가입 없이 결과가 바로 열리고, 광고 수신은 선택이에요.
  > ※ 세금 정보 제공용 참고 추정이며 투자 권유가 아닙니다.
- 이 DM 자체가 광고성 정보에 해당할 수 있으므로, **요청 받은 건에 대한 1회 응답**만 보내고 이후 홍보 DM은 폼에서 동의받은 뒤에만 발송합니다.
- 도구 예시: ManyChat / 채널톡 인스타 연동(도구 선택은 확인 후 결정)

※ 목표치는 업계 평균이 아니라 **초기 가설**입니다. 2주 실측 후 조정하세요.
