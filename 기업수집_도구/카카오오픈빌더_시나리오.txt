■ 오픈빌더 실제 설정 순서
══════════════════════════════════════════════════════════════

1. https://i.kakao.com 접속
2. 카카오 채널 연결 (채널 관리자 센터에서 생성 필요)
3. "챗봇 만들기" → 위 시나리오 순서대로 블록 생성
4. 각 블록에 응답 텍스트 입력 + 버튼 설정
5. 슬롯(변수) 설정: 업종, 매출, 급여, 전화번호
6. "배포" 버튼 클릭 → 카카오채널에 자동 연결
7. 절세_챗봇.html을 웹서버/깃허브페이지에 올린 후
   링크를 오픈빌더 버튼의 "웹링크"에 붙여넣기

■ 절세_챗봇.html 무료 호스팅 방법
══════════════════════════════════════════════════════════════

방법 1. GitHub Pages (무료, 추천)
  - GitHub에 파일 업로드
  - Settings → Pages → Branch: main 선택
  - URL: https://[계정명].github.io/[저장소명]/절세_챗봇.html

방법 2. Netlify (무료)
  - https://netlify.com 접속
  - HTML 파일 드래그 앤 드롭
  - 자동으로 링크 생성

방법 3. 카카오 채널 포스팅에 링크 삽입
  - 채널 소식에 링크 공유
  - 인스타/블로그 프로필 링크에 삽입
