# 🎬 롱폼 → 쇼츠 생성기

긴 영상 1개 → 하이라이트 자동 선별 → 9:16 쇼츠 mp4 + 단어별 강조 자막 + 상단 훅 문구 + 업로드용 제목·설명·해시태그 시트.

## 동작 순서
1. **대본 추출** – 내 컴퓨터에서 faster-whisper로 한국어 음성 인식 (영상이 외부로 나가지 않음, 무료)
2. **하이라이트 선별** – 대본을 Claude에 보내 훅·흐름·가치·트렌드 4축으로 점수화, 문장 경계로 시작/끝 보정, 겹침 제거
   (API 키가 없으면 규칙 기반으로 대체)
3. **9:16 렌더링** – 기본은 이지컷 스타일 `stack`: 검은 배경 · 상단 2줄 제목(둘째 줄 청록 강조) · 가운데 정사각 영상(가로 영상은 얼굴 쪽으로 자름) · 영상 위 박스 자막 · 하단 문구(예: 댓글 CTA).
   그 밖에 `fit`(블러 배경 위 전체 보이기), `crop`(꽉 채우기), 자막 `karaoke`(말하는 단어 노랑 강조)도 선택 가능. 음량은 -14 LUFS로 정규화
4. **산출물** – `output/<영상이름>/clips/short_01.mp4 …`, `upload_sheet.csv`, `clips.json`, `transcript.json`

## 설치 (한 번만)
1. Python 3.10+ 과 **ffmpeg** 설치 (Mac: `brew install ffmpeg` / Windows: `winget install ffmpeg`)
2. 터미널에서 이 폴더로 이동 후 `pip install -r requirements.txt`
3. Claude 분석을 쓰려면 환경변수 `ANTHROPIC_API_KEY` 설정 (또는 화면 왼쪽에 입력). **키는 채팅/코드에 붙이지 마세요.**
4. 자막 글꼴: Windows·Mac은 기본 한글 글꼴을 자동 사용합니다. 리눅스는 Noto Sans KR 설치 또는 `fonts/` 폴더에 .ttf를 넣으세요.

## 사용
- 화면으로: `streamlit run app.py`
  - **내 프로젝트**: 만든 작업 목록(쇼츠 개수·원본 길이·날짜)
  - **프로젝트 상세**: 쇼츠마다 바이럴 점수, 미리보기, ⬇다운로드, ✎편집하기(제목·시작/끝·화면 구성·자막·하단 문구 수정 후 다시 렌더링), 원본 타임라인(mm:ss), AI 하이라이트 한 줄, 스크립트, 훅·흐름·가치·트렌드 점수, 업로드 제목·설명, ⬇모든 쇼츠 다운로드
- 명령어로: `python -m shortsgen 영상.mp4 -n 5 --footer "댓글에 '세금' → 3분 계산기" --avoid "조합,수익 보장" --audience "병원 원장님"`
  - 이미 자막이 있으면 `--transcript 자막.srt` (음성 인식 생략, 빠름)
  - 키 없이 시험: `--no-llm`

## 주의
- 유튜브 링크는 **본인 소유이거나 사용 허락을 받은 영상**에만 사용하세요 (타인 영상 무단 사용은 저작권·플랫폼 약관 문제).
- 금지어 옵션은 단순 문자열 포함 검사입니다. 금융·의료 표현은 업로드 전 사람이 한 번 더 확인하세요(결과 화면의 '주의' 표시도 참고용).
- 점수는 모델이 매긴 추정치이며 실제 조회수를 보장하지 않습니다.
- 얼굴 추적은 OpenCV 기본 얼굴 검출(정면 얼굴 위주)이라, 인물이 여럿이거나 옆모습이면 `fit`을 권장합니다.

## 한계 (정직하게)
- 개발 환경에서는 음성 인식 모델 다운로드·유튜브 접속이 막혀 있어, **음성 인식 단계와 Claude 호출은 이 환경에서 실행해 보지 못했습니다.** 대본 이후 단계(선별 후처리·렌더링·CSV)는 테스트 7개와 합성 영상으로 검증했습니다. 처음 1회는 짧은 영상으로 시험해 보세요.
- 이지컷에 있는 요금제·크레딧, 유튜브 댓글 카드 오버레이, 웹 서비스 형태(로그인·클라우드 처리)는 만들지 않았습니다. 화면 인식 기반 장면 분석, 말하는 사람 전환 추적, 자동 B-roll도 아직 없습니다.
- '바이럴 점수'는 훅·흐름·가치·트렌드 가중 평균(모델 추정)이며 일부러 엄격하게 매깁니다. 다른 서비스 점수와 직접 비교하지 마세요.
